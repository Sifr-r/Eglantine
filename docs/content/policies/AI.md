# AI Policy

AI-assisted contributions are welcome and evaluated under the same quality, review, testing, and licensing standards as any other contribution.

## Expectations

1. **Review and ownership.** Contributors are responsible for the accuracy, completeness, and intent of the changes they submit, regardless of which tools assisted in writing them.
2. **Testing.** Verify your changes before opening a pull request or marking it ready for review, and report the checks you ran along with their scope and any limitations.
3. **Code quality.** Submitted code should follow the [Coding guidelines](./Coding.md) and match the surrounding codebase conventions.
4. **Clear descriptions.** Commit messages and pull request descriptions should be concise, accurate, and clearly explain the intent behind the change and how it was verified.
5. **Licensing.** All submitted code must be compatible with the GPLv3 or later, and you must have the right to contribute it under those terms.
6. **Data privacy.** Never send secrets, credentials, private user data, unpublished security reports, console keys, firmware, or copyrighted game data to third-party services.
