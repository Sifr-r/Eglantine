# `core`, `common`, `audio_core`, and `network`

Entry points: `src/core/core.cpp`, `src/common/host_memory.cpp`, `src/audio_core/`, `src/network/`.

## `core` — Machine, Platform, and Teardown

- **Ownership & CLI:** `Core::System` owns CPU, memory, and the service dispatcher. `Core::LaunchParams` / `ParseLaunchParams` / `ApplyLaunchParams` (`src/core/launch_params.{h,cpp}`) handle `-c`, `-g`, `-u`, `-d`, `--mcp`, NUP pack/unpack/edit, and Windows `argv_w` (`[launch_params]`). `Core::g_nx2_present_count` tracks frames for NX2 diagnostics/scripts.
- **Platform profile (`Core::PlatformProfile`):** `src/core/platform_profile.{h,cpp}` + `Loader::AppLoader::ReadProgramMetadata` (`src/core/loader/loader.h`) resolve `Switch1` vs `Switch2` once pre-kernel from the active loader, ExeFS, and update (`EDEN_NX2_PLATFORM` override). `nvhost_ctrl_gpu::GetCharacteristics3` fails closed (`NvResult::NotSupported`) on `0xD0` Switch 2 queries under `ConfirmedSwitch1`/`OverrideSwitch1`, and warns-and-allows under `DefaultSwitch1` (`[platform-profile]`).
- **Session-owned Switch 2 state (`Core::Nx2SessionState`):** `src/core/nx2_session_state.{h,cpp}` owns `Nx2SemaphoreWaiters`, async report counters, `Nx2GpuMemoryRegistry`, semaphore regions, and sparse state backed by an immortal heap `HandleRegistry` (64-slot fast table + overflow map). `EnsureNx2Session()` attaches on demand when `allow_contradictory_nx2_gpu_query` permits; `Nx2Session()` uses atomic `has_nx2_session` (null on Switch 1); `Retire()` clears/detaches; `System::Impl::TeardownSubsystems()` pairs with `EndNx2Session()` and legacy reset when `!HasActiveSessions()` (`[nx2-session]`).
  - Migrated callers: `Tegra::MemoryManager::System()`, GPU engines (`puller.cpp`, `maxwell_3d.cpp`, `kepler_compute.cpp` with `weak_ptr` on `SignalFence`), `nvdrv` (`nvdrv.cpp`, `container.cpp`, `nvhost_ctrl_gpu.cpp`, `nvhost_as_gpu.{h,cpp}`), `nx2_gsv.h`, `TextureCache`, `Vulkan::TextureCacheRuntime`, `QueryCache` (<= 32B SBO on `CounterReport`), `gpu_split.cpp`, `null_rasterizer.cpp`.
- **Dynamic platform sizing:** `Switch1` = `4` cores, `34`-bit device VA; `Switch2` = `6` cores, `36`-bit device VA. `KernelCore::IsInitialized()` gates `SetPlatformProfile()` / `SetActiveCoreCount()`. `svc_thread.cpp` validates masks pre-fold, folds Switch 2 virtual cores `6..7` onto `0..5`, and rejects zero masks. `Core::DeviceMemoryManager` (`src/core/device_memory_manager.{h,inc}`) enforces `IsInBounds`, page-crossing `Read<T>`/`Write<T>`, `size == 0`/null guards, lock-ordered `SetDeviceAddressBits()` (`counter_guard` before `mapping_guard`), and bounds/ASID checks (`[platform-sizing]`, paired with `Common::FlatAllocator` & `Common::SparseLargeVector`).
- **Kernel object list & shutdown order:** Objects live in the guest RAM arena, which frees before kernel destruction. `KAutoObjectWithListContainer::Finalize()` / `KernelCore::ClearObjectList()` unlink all objects in `~Impl()`. `ShutdownMainProcess()` pauses `core_timing.SyncPause(true)` for full teardown and resets the cheat engine before releasing processes. `TeardownSubsystems()` runs `CancelBlockingGets` -> `KernelCore::CloseServices` (two-pass stop) -> join core/service threads -> `KernelCore::DestroyServices`. `CoreTiming::Advance()` copies events to locals before callback execution; `KThread::FinishTermination()` (`k_thread.cpp`) drops `KScopedSchedulerLock` before `this->Close(kernel)` (`[shutdown-ordering]`).
- **NX2 present shutdown & timing/IPC/memory:** Emulation stop token wakes `INx2Vi2Session` guest fence events before composite/release. `CoreTiming::GetClockTicks()` keeps Switch 2 fixed at `31.25 MHz` across Boost/Overclock (`[guest_counter]`). `ArmDynarmic64` uses atomic `code_generation` for `MemoryReadCode()`. `HLERequestContext::ReadOutputBuffer()` (`hle_ipc.{h,cpp}`) prefills `OutBuffer` scratch from B/C descriptors (`src/tests/core/cmif_out_buffer.cpp`). `Memory::Impl::GetSpan` (`memory.cpp`) validates `current_page_table`, `AddressSpaceContains`, and contiguous host pointers (`src/tests/core/memory_span.cpp`).
- **Services, saves, and NUP:**
  - `FileSys::SaveDataFactory` (`savedata_factory.cpp`) owns disk layout (`save/<id>/<uid>`, `save/0/<uid>/<tid>`, `save/cache/<tid>[_<idx>]`, `<id>/<uid>/<tid>`). `SaveDataController` (`save_data_controller.cpp`) is the sole HLE boundary; `FspSrv` (`fsp_srv.cpp`) implements 18 commands (`InvalidateBisCache` is a no-op; `RegisterSaveDataFileSystemAtomicDeletion` (24) deletes immediately). Deletes are idempotent (`ResultTargetNotFound` when absent) and never escape space roots.
  - `ContentProviderUnion` starts initialized (`core.cpp`); `ManualContentProvider::SwapEntries()` swaps atomically (`src/tests/core/content_provider_init.cpp`); `AppLoader_NUP` (`nup.cpp`, `WithPlatformOf`) preserves native Switch 2 base ExeFS under legacy updates; `nup_writer.cpp` preserves extents when moving metadata (`[nup]`).
- **GPU callback/session lifetime & guest bounds:** GPU-thread callbacks must not capture `this`, raw `KEvent*`, or raw `Memory*` — use shared `alive` state (`INx2SyncptSession::m_shared`, `INx2Vi2Session::m_frame_waiter`, `INx2GraphicsSystemSession::m_syncpt_state`) and drain GPU work in destructors. `nvhost_as_gpu` lock order: `Nx2GpuMemoryRegistry::mutex -> nvhost_as_gpu::mutex -> Container::session_guard -> device_mutex -> smmu` (never mutate registry inside `WithSession`). `INx2GpuSession` uses non-recursive mutex/CV + eager `AllocateGpuOnlyBacking` outside `m_region_mutex`. `nx2:gpu` cmd 214 bounds page alignment, VA range, and an 8 GiB per-region limit; `NvMap::PinHandle` rejects closed sessions.

## `common` — Host Memory & Scratch Safety

- **Windows on-demand DRAM commit (`src/common/host_memory.{h,cpp}`):** Reserves via `CreateFileMapping2(..., SEC_RESERVE)` / `VirtualAlloc(..., MEM_RESERVE)` and commits 64 KiB granules on fault in `HostMemoryFaultHandler` (`SRWLOCK`), chaining unmapped/`PAGE_READONLY`/`PAGE_NOACCESS` faults to Dynarmic SEH. `Protect()` leaves untouched `MEM_RESERVE` pages uncommitted and commits target protection flags; `EnsureHostMemoryCommitted` pre-commits for `Vulkan::HostImporter`; `Release()` is idempotent (`[host_memory]`).
- **Scratch OOM safety:** `Common::ScratchBuffer::resize_destructive()` (`scratch_buffer.h`) calls `release()` before allocating (`[scratch_oom]`).

## `audio_core` and `network`

- **`audio_core` (`src/audio_core/`):** Opus decoders (`opus_decode_object.{h,cpp}`, `opus_multistream_decode_object.{h,cpp}`, `opus/decoder.cpp`) convert byte capacity to complete interleaved PCM frames and bound IPC output copies. `info_updater.cpp`, `splitter_context.cpp`, and `decode.cpp` validate indices/sections/ADPCM bounds. `Sink::SinkStream` (`sink_stream.{h,cpp}`) keeps `std::jthread silent_device` declared last (`StartSilentDevice()`/`StopSilentDevice()`); `CubebSink` (COM-MTA watchdog) and `SDLSinkStream` recover on stall/hotplug (`[audio_recovery]`).
- **`network` (`src/network/`):** ENet `room.cpp` & `room_member.cpp` share the wire protocol. `Packet::Read` checks remaining bytes before resizing/copying; only authenticated `members` (never peer-chosen nicknames) hold moderation/relay privileges; relayed packets have source IP bytes `2..5` overwritten with the room-assigned fake IP and payload capped pre-copy.
